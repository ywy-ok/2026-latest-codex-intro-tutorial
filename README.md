## 贡献指南

欢迎通过 Issue 和 Pull Request 参与改进本仓库。

- 提交前请先确认内容准确、表述清晰，并尽量补充可靠的参考来源。
- 请从 `main` 新建描述清晰的分支进行修改，不要直接推送到 `main`。
- 每个 Pull Request 应聚焦一个主题，并简要说明修改内容和原因。
- 提交前请确认自动检查能够通过，且不要提交密码、令牌、个人隐私或其他敏感信息。
- 合并前需要经过至少 1 位协作者的审查批准；仓库管理员可按当前规则绕过此限制。
